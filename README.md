# Analytics & BI Portfolio — Synthetic Data Projects

This repository contains a collection of **analytics and BI projects** built using **synthetic (dummy) data** to demonstrate data modeling, analytical thinking, and dashboard design across different business domains.

All projects in this repository are designed for:
- learning and experimentation
- portfolio demonstration
- knowledge sharing (e.g. LinkedIn, blog posts)

> ⚠️ **Disclaimer**  
> All datasets are entirely synthetic.  
> No real users, companies, operators, or proprietary data are used.

---

## What You’ll Find in This Repository

Each subfolder represents a **self-contained analytics project**, typically including:
- one or more dashboards (e.g. Power BI)
- supporting datasets (CSV)
- domain-specific KPIs
- documented assumptions and limitations

Projects may vary in:
- data model structure
- level of detail
- business domain
- metrics and definitions

This is intentional.
